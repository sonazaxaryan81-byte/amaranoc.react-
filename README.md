# Amaranoc.am — Vanilla JS Clone

Ուսումնական նախագիծ՝ ստեղծված Vite + Vanilla JavaScript + HTML + CSS տեխնոլոգիաներով։

## Տեղային աշխատեցում

```bash
npm install
npm run dev
```

Vite-ը կտա տեղային հասցե, սովորաբար՝ `http://localhost:5173/`։

## Production build

```bash
npm run build
npm run preview
```

## Կառուցվածք

```text
amaranoc-clone/
├── index.html
├── package.json
├── README.md
└── src/
    ├── main.js
    ├── css/
    │   └── style.css
    └── js/
        ├── app.js
        └── data.js
```

## Իրականացված հնարավորություններ

- Ամառանոցների քարտերի ցանց և առանձնացված լավագույն առաջարկներ
- Որոնում ըստ անվան և վայրի
- Գնի, մարդկանց քանակի և հարմարությունների ֆիլտրեր
- Արժույթի ընտրություն (AMD, USD, EUR, RUB)
- Գնի դասավորում
- Նախընտրածների ցանկ
- Տան մանրամասների պատուհան
- Զեղչերի, ծառայությունների, մեր մասին, կարծիքների և կապի բաժիններ
- Կապի ձևի վավերացում
- Հեռախոսի համար հարմարեցված responsive դիզայն

## Նշում

Սա ուսումնական front-end կրկնօրինակ է, ոչ թե amaranoc.am-ի պաշտոնական կամ backend-ին միացված տարբերակը։ Հայտարարությունների տվյալներն ու գները ցուցադրական են, իսկ լուսանկարները բեռնվում են Unsplash-ից։ Իրական ամրագրում, վճարում, օգտատիրոջ մուտք և քարտեզային API միացված չեն։
